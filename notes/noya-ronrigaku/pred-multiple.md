# 二変項の命題関数と多重量化（問題42・43）

## 使う公理系

なし（記号化の練習）。用語と記号は [pred-basics.md](pred-basics.md)。

### 必要な記号（復習）

- 二変項の命題関数 Fxy: 「x は y を愛する」（= 「y は x に愛される」）
- 自由変項: 量化されていない変項。束縛変項: 量化されている変項
- 自由変項が残っている式は命題関数、自由変項がなければ命題
- 議論領域: 人間（「人間である」は書かなくてよい）

## 問題42

「x は y を愛する」（=「y は x に愛される」）を Fxy と表わすことにする。次の命題関数を記号を用いて表わせ。ただし、議論領域は人間とする。

1. x はすべての人を愛する
2. x には愛する人がいる
3. すべての人は y を愛する
4. y を愛する人がいる

- 状態: 本の解答を確認済み

解答（本より）

| 問 | 日本語 | 記号化 | 自由変項 |
| --- | --- | --- | --- |
| (1) | x はすべての人を愛する | ∀yFxy | x |
| (2) | x には愛する人がいる | ∃yFxy | x |
| (3) | すべての人は y を愛する | ∀xFxy | y |
| (4) | y を愛する人がいる | ∃xFxy | y |

本文より: (1)(2) は x を自由変項とする一変項の命題関数、(3)(4) は y を自由変項とする一変項の命題関数。そこで (1)(2) は x を、(3)(4) は y を、さらに量化できる。

メモ

- どちらの変項を量化するかは、「愛する側（x）」か「愛される側（y）」のどちらに「すべて」「ある」が付いているかで決まる。
- (3) 「すべての人は y を愛する」は「y はすべての人から愛される」と同じ。

## 問題43

問題42で得られた命題関数について、以下にしたがってそれをさらに量化したものを、まず日本語で表わし、ついで記号を用いて表現せよ。

1. 命題関数「x には愛する人がいる」をさらに全称量化せよ。
2. 命題関数「y はすべての人から愛される」をさらに存在量化せよ。

- 状態: 本の解答を確認済み

解答（本より）

| 問 | 元の命題関数 | 日本語 | 記号化 |
| --- | --- | --- | --- |
| (1) | ∃yFxy（問題42(2)） | 誰にでも、愛する人がいる | ∀x∃yFxy |
| (2) | ∀xFxy（問題42(3)） | すべての人から愛される人がいる | ∃y∀xFxy |

メモ

- 自由変項がなくなったので、どちらも命題になった。
- **量化子の順番で意味が変わる。**
  - ∀x∃yFxy: 誰にでも愛する人がいる。愛される相手 y は x ごとに違ってよい。
  - ∃y∀xFxy: すべての人から愛される人（1人の y）がいる。y は全員に共通。
- ∃y∀xFxy ⊃ ∀x∃yFxy は成り立つ（みんなに愛される人がいれば、誰にでも愛する人がいる）。逆は成り立たない（各自が自分だけを愛していても、全員に愛される人はいない）。

Lean で書くと（α は議論領域の型、F : α → α → Prop）

```lean
∀ y, F x y        -- 問題42(1)（x は自由変項）
∃ y, F x y        -- 問題42(2)
∀ x, F x y        -- 問題42(3)（y は自由変項）
∃ x, F x y        -- 問題42(4)
∀ x, ∃ y, F x y   -- 問題43(1)
∃ y, ∀ x, F x y   -- 問題43(2)
```

Lean で確認済み（2026-10-12）:

- `(∃ y, ∀ x, F x y) → ∀ x, ∃ y, F x y` は証明できる（`fun ⟨y, h⟩ x => ⟨y, h x⟩`）。
- 逆向きは、議論領域を `Bool`、F x y を x = y としたときに反例になる。
