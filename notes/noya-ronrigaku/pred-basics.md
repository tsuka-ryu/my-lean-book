## 用語と記号

| 用語 | 意味 | 例 | 記号 |
| --- | --- | --- | --- |
| (1) 命題 | 真偽を問題にできる文 | 「チョビは犬である」「真知子は春樹を好きだ」「すべてのクジラは魚ではない」「誰もが誰かを好きである」 | |
| (2) 命題関数 | 命題の中の個体を表す表現を空欄にし、x, y, z, … で置き換えたもの。固有名から命題への関数 | 「x は犬である」「x は y を愛する」 | Fx, Gx, Fxy, … |
| (3) （個体）変項 | 命題関数の中の x, y, z, … | | x, y, z, … |
| (4) 述語 | 個体が満たす性質や関係を表す表現 | 「……は犬である」「……は……を愛する」 | F, G, H, … |
| (5) （個体）定項 | 変項の値となる固有名 | チョビ、真知子 | a, b, c, … |
| (6) 量化 | 命題関数の変項に「すべて」や「ある」という量を与えること | すべての x は犬である → ∀xFx、ある x は犬である → ∃xFx | |
| (7) 量化子 | ∀ を全称量化子、∃ を存在量化子と呼ぶ | | ∀, ∃ |

記号化の例

- 命題関数: Fx, Gx, Fy, Gy, Fxy, Gxy, …（述語 + 変項）
- 命題: Fa, Ga, Fb, Gb, Fab, Gab, …（述語 + 定項）

### (8) 量化の範囲

- ∃xFx ∧ Gx: 量化子は Fx の x だけにかかる。Gx の x は量化されていない。
- ∃x(Fx ∧ Gx): 括弧があるので、量化子は Fx ∧ Gx 全体の x にかかる。

**本の書き方では、量化子はカッコがなければ直後の式だけにかかる。**

### (9) 自由変項と束縛変項

- 自由変項: 量化されていない変項（Fx の x）。
- 束縛変項: 量化されている変項（∀xFx の x）。

| 式 | Fx の x | Gx の x |
| --- | --- | --- |
| ∃xFx ∧ Gx | 束縛 | 自由 |
| ∃x(Fx ∧ Gx) | 束縛 | 束縛 |

束縛変項は、実質的にはもはや変項ではない。

- Fx は命題関数で、x にはさまざまな定項が代入されうる。
- ∀xFx はもはや命題関数ではなく命題で、x にはいわばすべての定項が代入済みのような形になっている。
- 束縛変項は「みかけの変項」にすぎない。

そのため ∀xFx と ∀tFt は実質同じ。「∀☆F☆」（☆には同じ記号が入る）はすべて同じ命題を表す。

### (10) 議論領域

あらかじめ設定された対象の範囲を「議論領域（domain of discourse）」と言い、D で表す。議論領域が「人間」なら、人間であることはことさら言わなくてよい。

例: 「すべての人間は鳥ではない」（F: 人間である、G: 鳥である）

- 議論領域を定めない場合: ∀x(Fx ⊃ ¬Gx)
- 議論領域 D を人間の集合とした場合: ∀x¬Gx

### 命題か命題関数かの見分け方

**量化子がかかっていない変項（自由変項）が1つでも残っていれば命題関数、1つも残っていなければ命題。**

自由変項は「空欄」。空欄が残っていると、誰が入るか分からないので真偽が決まらない。

| 式 | 自由変項 | 種類 |
| --- | --- | --- |
| Fxy | x, y | 命題関数（空欄2つ） |
| ∃yFxy | x | 命題関数（空欄1つ） |
| ∀x∃yFxy | なし | 命題 |
| ∃yFay | なし | 命題（a は定項なので空欄ではない） |

空欄を埋める方法は2つ。

1. 定項を入れる: ∃yFxy → ∃yFay（a には愛する人がいる）
2. 量化する: ∃yFxy → ∀x∃yFxy（誰にでも愛する人がいる）

量化子を1つかけるごとに空欄が1つ減っていくイメージ。

Lean では、`∃ y, F x y` は x が文脈に無いと書けない（「x って何？」とエラーになる）。`∀ x, ∃ y, F x y` なら単独で意味が通る `Prop` になる。

### 自由変項・束縛変項と議論領域の違い

ごっちゃになりやすいが、別の問いに答えている。

| | 答えている問い | 例 |
| --- | --- | --- |
| 自由変項・束縛変項 | その変項に、もう量化子がかかっているか？（式の形で決まる） | ∃yFxy の y は束縛、x は自由 |
| 議論領域 | 変項が**どの範囲のもの**を動くのか？（「すべて」「ある」が何の中での話か） | 「すべて」が「すべての人間」の意味になる |

議論領域は、自由か束縛かとは独立に、変項全体の範囲を決める。

- 束縛変項にとって: 量化子がどの範囲を動くか
- 自由変項にとって: 空欄に何を入れられるか

議論領域を決めると、「人間である」のような述語を毎回書かなくてよくなる（議論領域なしなら ∀x(Hx ⊃ …)、∃x(Hx ∧ …) と書く必要がある）。

Lean では、議論領域は**型**、自由か束縛かは **∀ や ∃ が付いているかどうか**で、見た目からして別物。

## メモ

- 命題関数 Fx は、x に定項を入れると命題になる（Fa）、または量化すると命題になる（∀xFx）。x が空欄のままの Fx は、真偽が決まらないので命題ではない。
- 自由変項が残っている式は命題関数（真偽が決まらない）。自由変項が1つもなければ命題。∃xFx ∧ Gx は Gx の x が自由なので、まだ命題ではない。
- 束縛変項の名前は自由に付け替えてよい（∀xFx = ∀tFt）。プログラムの関数の引数名を変えても中身が同じなのと同じ。
- 述語と命題関数の違い: 述語 F は「……は犬である」という空欄つきの表現そのもの。命題関数 Fx は、その空欄に変項 x を入れたもの。

## Lean との対応

| 本 | Lean |
| --- | --- |
| 個体の集まり（議論領域 D） | 型 `α`（例: `(α : Type)`） |
| 定項 a | `a : α` |
| 述語 F（1引数） | `F : α → Prop` |
| 述語 F（2引数、関係） | `F : α → α → Prop` |
| Fa | `F a` |
| Fab | `F a b` |
| ∀xFx | `∀ x, F x` |
| ∃xFx | `∃ x, F x` |

「命題関数は固有名から命題への関数」という本の説明が、Lean では `α → Prop` という型そのものになっている。

**量化の範囲は本と Lean で逆なので注意。** Lean の `∀ x,` や `∃ x,` は、カッコがなければ**できるだけ右まで**かかる。

| 本 | Lean |
| --- | --- |
| ∃xFx ∧ Gx | `(∃ x, F x) ∧ G x` |
| ∃x(Fx ∧ Gx) | `∃ x, F x ∧ G x` |

束縛変項の名前の付け替え: Lean でも `∀ x, F x` と `∀ t, F t` は全く同じ式として扱われる（`rfl` で等しい）。

議論領域: Lean では、量化する変数には必ず型が付くので、その型が議論領域にあたる。

| 本 | Lean |
| --- | --- |
| 議論領域を定めない: ∀x(Fx ⊃ ¬Gx) | `∀ x : α, F x → ¬G x`（α は何でも入る型、F は「人間である」） |
| D = 人間: ∀x¬Gx | `∀ x : Human, ¬G x`（型 Human が議論領域） |
