# 多重量化の記号化練習（問題44〜46）

## 使う公理系

なし（記号化の練習）。用語と記号は [pred-basics.md](pred-basics.md)、問題42・43は [pred-multiple.md](pred-multiple.md)。

### 必要な記号（復習）

- 二変項の命題関数 Fxy: 「x は y を愛する」（= 「y は x に愛される」）
- 「すべての F は G」→ ∀x(Fx ⊃ Gx)、「ある F は G」→ ∃x(Fx ∧ Gx)
- 量化子の順番で意味が変わる: ∀x∃yFxy（誰にでも愛する人がいる）と ∃y∀xFxy（すべての人から愛される人がいる）は違う
- 量化子がかかっていない変項が1つでも残っていれば命題関数、1つも残っていなければ命題
- 議論領域を決めると、範囲を絞るための述語（「人間である」など）を省略できる

### 問題42の命題関数（議論領域は人間）

| 問 | 日本語 | 記号化 | 自由変項 |
| --- | --- | --- | --- |
| (1) | x はすべての人を愛する | ∀yFxy | x |
| (2) | x には愛する人がいる | ∃yFxy | x |
| (3) | すべての人は y を愛する | ∀xFxy | y |
| (4) | y を愛する人がいる | ∃xFxy | y |

## 問題44

問題42で得られた命題関数について、以下にしたがってそれをさらに量化したものを、まず日本語で表わし、ついで記号を用いて表現せよ。

1. 命題関数「x はすべての人を愛する」をさらに存在量化せよ。
2. 命題関数「y を愛する人がいる」をさらに全称量化せよ。

- 状態: 本の解答を確認済み

解答（本より）

| 問 | 日本語 | 記号化 |
| --- | --- | --- |
| (1) | すべての人を愛する人がいる | ∃x∀yFxy |
| (2) | 誰でも誰かに愛されている | ∀y∃xFxy |

メモ

- 外側に付けた量化子が、日本語では文の主語側に来る。(1) は「（ある x が）すべての人を愛する」、(2) は「（どの y も）誰かに愛されている」。
- 問題43との比較。量化子の順番と、どちらの変項にかかるかで4通りの意味になる。

| 式 | 意味 |
| --- | --- |
| ∀x∃yFxy | 誰にでも愛する人がいる（問題43(1)） |
| ∃y∀xFxy | すべての人から愛される人がいる（問題43(2)） |
| ∃x∀yFxy | すべての人を愛する人がいる（問題44(1)） |
| ∀y∃xFxy | 誰でも誰かに愛されている（問題44(2)） |

## 問題45

次を述語論理の記号を用いて表わせ。（議論領域 D を人間とする。）

1. 誰もが無門のことを好きだ
2. 道元には誰か好きな人がいる
3. 誰にでも、誰か好きではない人がいる
4. 誰からも好かれる人はいない

- 状態: 本の解答を確認済み

解答（本より）: 無門を a、道元を b、「x は y を好きだ」を Fxy とする。

| 問 | 日本語 | 記号化 |
| --- | --- | --- |
| (1) | 誰もが無門のことを好きだ | ∀xFxa |
| (2) | 道元には誰か好きな人がいる | ∃xFbx |
| (3) | 誰にでも、誰か好きではない人がいる | ∀x∃y¬Fxy |
| (4) | 誰からも好かれる人はいない | ¬∃y∀xFxy |

メモ

- (1)(2) は定項（a, b）が入るので、量化子は1つで済む。F の第1引数が「好きな側」、第2引数が「好かれる側」なのに注意（(1) は Fxa、(2) は Fbx）。
- (3) は「好きではない」なので ¬ は Fxy の直前。∀x∃y の形は問題43(1) と同じ。
- (4) は「誰からも好かれる人がいる」（∃y∀xFxy、問題43(2)）の全体を否定したもの。

## 問題46

「自然数に最大数は存在しない」を Fxy: x ≧ y という命題関数を用いて、次の議論領域 D のもとで記号化せよ。

1. D: 自然数
2. D: 実数

- 状態: 本の解答を確認済み

解答（本より）: Fxy: x ≧ y

| 問 | 議論領域 | 記号化 |
| --- | --- | --- |
| (1) | 自然数 | ¬∃x∀yFxy |
| (2) | 実数 | ¬∃x(Nx ∧ ∀y(Ny ⊃ Fxy))（Nx: x は自然数である） |

メモ

- 「最大数がある」= 「すべての y 以上である x がある」= ∃x∀yFxy。それを否定して「最大数は存在しない」。

組み立て方（詳しく）

1. 「x が最大数である」= 「x はどの y と比べても y 以上」= ∀yFxy（x が空欄なのでまだ命題関数）
2. 「最大数が存在する」= x を ∃ で量化して ∃x∀yFxy
3. 「最大数は存在しない」= 否定して ¬∃x∀yFxy。議論領域が自然数ならこれで完成（(1) の答え）。
   - 確認: どんな自然数 x でも、y = x + 1 とすれば x ≧ y は成り立たない。だから真。
4. 議論領域が実数だと、¬∃x∀yFxy は「**実数**に最大数は存在しない」になってしまう。「自然数である」を Nx で書き足す必要がある。
5. N が必要な変項は2つ。
   - x: 最大数の候補は自然数 → 「ある自然数 x」なので ∃x(Nx ∧ …)
   - y: 比べる相手も自然数だけ → 「すべての自然数 y」なので ∀y(Ny ⊃ Fxy)
   - 合わせて否定すると ¬∃x(Nx ∧ ∀y(Ny ⊃ Fxy))（(2) の答え）
6. ∧ と ⊃ を逆にすると壊れる（[pred-basics.md](pred-basics.md) の「範囲を絞った量化」）。
   - ∃x(Nx ⊃ …): x = 0.5 を選ぶと Nx が偽なので自動的に真。中身が何でも真になる。
   - ∀y(Ny ∧ Fxy): 「すべての実数は自然数」を含むので、0.5 で常に偽になる。
7. N を片方だけに付けると、別の命題になる。

| 式 | 意味 |
| --- | --- |
| ¬∃x(Nx ∧ ∀y(Ny ⊃ Fxy)) | どの自然数も、すべての自然数以上ではない ✅ |
| ¬∃x∀y(Ny ⊃ Fxy) | どの**実数**も、すべての自然数以上ではない（x を制限していない） |
| ¬∃x(Nx ∧ ∀yFxy) | どの自然数も、すべての**実数**以上ではない（y を制限していない） |

下の2つもたまたま真だが、「自然数に最大数はない」とは別の主張。

Lean では、議論領域が型になるので N は不要。(1) は証明も短い（動作確認済み、2026-10-12）。

```lean
example : ¬∃ x : Nat, ∀ y : Nat, x ≥ y := by
  intro ⟨x, h⟩
  have := h (x + 1)   -- y = x + 1 を当てはめると x ≥ x + 1
  omega               -- それは矛盾
```
- (2) は議論領域が実数なので、「自然数である」を述語 N で書く必要がある。x にも y にも付ける。
- 付け方は「∀ には ⊃、∃ には ∧」の型どおり: ∃x(Nx ∧ …)、∀y(Ny ⊃ …)。
- (2) で N を書かずに ¬∃x∀yFxy とすると、「実数に最大数は存在しない」という別の命題になる。議論領域を決めると述語を省略できる、の逆パターン。
