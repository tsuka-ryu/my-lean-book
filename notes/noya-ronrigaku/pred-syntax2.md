# 述語論理の構文論（第4節）：全称汎化・存在汎化（問題51・52）

## 使う公理系：述語論理の公理系（LP の拡張）

命題論理の公理系 LP に、量化子に関する規則（導入則と除去則、4つ）を付け加えたもの。全称例化は [pred-syntax.md](pred-syntax.md)。

### 命題論理の規則（LP より）

詳しくは [lp.md](lp.md)。

- 演繹規則 DR: A を仮定して B が導出されるとき、A という仮定なしに A ⊃ B を導出してよい
- 前件肯定式 MP: A, A ⊃ B から B を導出してよい
- 背理法: A ⊃ (D ∧ ¬D) から ¬A を導出してよい
- 二重否定: ¬¬A から A を導出してよい
- 結合: A, B から A ∧ B を導出してよい
- 分離: A ∧ B から A を、A ∧ B から B を導出してよい
- ∨入れ: A から A ∨ B を、B から A ∨ B を導出してよい
- ∨取り: A ∨ B, A ⊃ C, B ⊃ C から C を導出してよい

### 量化子の規則

- 全称例化（∀ の除去則）: ∀xAx から At を導いてよい
- 全称汎化（規則9、∀ の導入則）: At から ∀xAx を導出してよい（ただし、t は限定なしの項）
- 存在汎化（規則11、∃ の導入則）: At から ∃xAx を導出してよい（t は任意の項）

述語論理の公理系 L の全規則は [pred-l.md](pred-l.md)。

### 仮定の書き方

- [2(t)] は「2行目の仮定で、その仮定に t が含まれている」ことを表す。全称汎化の条件（t が仮定に現れてはならない）をチェックするための印。
- このように仮定に現れている t を「**限定つきの項**」と呼ぶ（問題51の解答より）。限定つきの項は全称汎化できない。
- 仮定 2(t) が DR や背理法で外れると、t は限定つきではなくなり、全称汎化できるようになる。

### 証明の仕方・仮定の扱い（LP と同じ）

1. 各行には、仮定、定理、先行する行から導出規則で導出できる式のいずれかを書く。
2. 目的の式が仮定なしに書き出されたら終わり。
3. A を n 行目で仮定するときは A [n]。導出に使った式の仮定はすべて受け継がれ、DR（や背理法）で外した仮定だけが消える。

## 問題

### 問題51

次の偽定理に対する偽証明の誤りを指摘せよ。

偽定理 ¬∀xFx ⊃ ∀x¬Fx

| 行 | 論理式 | 仮定 | 根拠 |
| --- | --- | --- | --- |
| 1 | ¬∀xFx | [1] | 仮定 |
| 2 | Ft | [2(t)] | 仮定 |
| 3 | ∀xFx | [2(t)] | 2 と全称汎化 |
| 4 | ∀xFx ∧ ¬∀xFx | [1, 2(t)] | 3, 1 と結合 |
| 5 | ¬Ft | [1] | 2, 4 と背理法 |
| 6 | ∀x¬Fx | [1] | 5 と全称汎化 |
| 7 | ¬∀xFx ⊃ ∀x¬Fx | なし | 1, 6 と DR |

- 状態: 本の解答を確認済み

解答（本より）: (2) から (3) がまちがい。Ft [2(t)] における t は限定つきの項であるから全称汎化できない。

メモ

- 3行目の Ft は仮定 2(t) に依存していて、その仮定に t が含まれている。だから t は「何でもいい t」ではなく「Ft を満たすと仮定した特定の t」。特定の1つが F だからといって、すべてが F とは言えない。
- 6行目の全称汎化は OK。5行目 ¬Ft は仮定 [1]（¬∀xFx）にしか依存しておらず、[1] には t が現れない（仮定 2(t) は背理法で外れている）。
- 直感: 全称汎化は「**何でもいい t** について A が示せたなら、すべての x について A」という規則。t について何も仮定していないときだけ「何でもいい」と言える。
- 意味で考えても偽: D = 動物、Fx = x は肉食である とすると、¬∀xFx（すべての動物が肉食、ではない）は真、∀x¬Fx（どの動物も肉食でない）は偽。真 ⊃ 偽 で偽。
- 正しいのは ¬∀xFx ⊃ ∃x¬Fx（ド・モルガンの量化子版）。

### 問題52

次の定理に対する証明の空欄を埋めよ。

定理 ¬∃xFx ⊃ ∀x¬Fx

| 行 | 論理式 | 仮定 | 根拠 |
| --- | --- | --- | --- |
| 1 | ¬∃xFx | [1] | 仮定 |
| 2 | Ft | [2(t)] | 仮定 |
| 3 | （イ） | [2(t)] | 2 と存在汎化 |
| 4 | ∃xFx ∧ ¬∃xFx | [1, 2(t)] | 3, 1 と結合 |
| 5 | ¬Ft | [1] | 2, 4 と背理法 |
| 6 | （ロ） | [1] | 5 と全称汎化 |
| 7 | ¬∃xFx ⊃ ∀x¬Fx | なし | 1, 6 と DR |

- 状態: 本の解答を確認済み

解答（本より）: （イ）∃xFx　（ロ）∀x¬Fx

メモ

- 3行目（イ）: 存在汎化「At から ∃xAx」に、At = Ft を当てはめて ∃xFx。存在汎化には仮定の条件はない（t が限定つきでもよい）。「この t が F なら、F であるものがある」は、t が何であっても言える。
- 4〜5行目: ∃xFx と ¬∃xFx で矛盾ができたので、背理法で仮定 2(t)（Ft）を否定して ¬Ft。ここで仮定 2(t) が外れ、t は限定つきでなくなる。
- 6行目（ロ）: ¬Ft は [1]（¬∃xFx）にしか依存せず、[1] に t は現れないので全称汎化できて ∀x¬Fx。
- 問題51と証明の形はそっくり。違いは3行目だけ。問題51は限定つきの t を全称汎化した（ダメ）、問題52は存在汎化した（OK）。
- 意味: 「F であるものが1つもない」なら「どれも F でない」。ド・モルガンの量化子版の片方向。

詳しい解説

例: D = ペンギン、Fx = x は空を飛ぶ。「飛ぶペンギンが1羽もいないなら、どのペンギンも飛ばない」。

作戦（ゴールから逆算）

1. 一番外側は ⊃ → 左の ¬∃xFx を仮定（1行目）、最後に DR。次の目標は ∀x¬Fx。
2. ∀ を作れるのは全称汎化だけ → 次の目標は ¬Ft（t は限定つきでないこと）。
3. ¬ を作れるのは背理法 → Ft を仮定（2行目）して矛盾を目指す。
4. Ft から存在汎化で ∃xFx を作れば、1行目と矛盾する。

```
仮に ¬∃xFx としよう ──────────────────────────────┐ [1]
│ 仮に Ft としよう ─────────────────────┐ [2(t)]  │
│ │ ∃xFx（存在汎化）                    │         │
│ │ ∃xFx ∧ ¬∃xFx（矛盾！）              │         │
│ └────────────────────────────────────┘         │
│ ¬Ft（背理法で箱を閉じる）                         │
│ ∀x¬Fx（全称汎化。t はもう限定つきでない）           │
└────────────────────────────────────────────────┘
¬∃xFx ⊃ ∀x¬Fx
```

t の立場の変化（この証明のカギ）

| 行 | t の立場 | 全称汎化 |
| --- | --- | --- |
| 2〜4行目 | 限定つき（「飛ぶ」と仮定した特定の t） | できない |
| 5〜6行目 | 限定なし（何でもいい t） | できる |

問題51は限定つきの段階で全称汎化したので誤り。問題52は仮定 2(t) を背理法で外して限定が解けてから全称汎化しているので正しい。6行目までの議論は t について何も特別なことを使っていないので、t がどのペンギンでも成り立つ。

つまずいた点: 5行目の背理法（「t が飛ぶと仮定したら矛盾した。だから t は飛ばない」）が飛躍に感じた。

- 5行目は実は2ステップを1行にまとめている。

```
4.  ∃xFx ∧ ¬∃xFx              [1, 2(t)]
4'. Ft ⊃ (∃xFx ∧ ¬∃xFx)       [1]        ← DR で仮定 2(t) を外す（箱を閉じる）
5.  ¬Ft                       [1]        ← 背理法（A ⊃ (D ∧ ¬D) から ¬A）
```

- 「□ ⊃ 矛盾」から「¬□」が言える理由は ⊃ の真理値表。矛盾（D ∧ ¬D）は常に偽。右が偽なのに ⊃ 全体が真になれるのは、左（Ft）が偽のときだけ。「真から偽は出てこない。偽が出てきたなら出発点が偽」。

| Ft | 矛盾 | Ft ⊃ 矛盾 |
| --- | --- | --- |
| 真 | 偽 | 偽 |
| 偽 | 偽 | 真 |

- 矛盾は仮定1と仮定2の両方から出たのに、なぜ Ft を否定するのか → 仮定1は否定していない（5行目の仮定欄は [1] のまま）。「¬∃xFx という前提のもとでは、Ft は成り立たない」と言っている。どちらを捨てるかはこちらが選べ、今は ¬Ft が欲しいので Ft を捨てる。

Lean で書くと（動作確認済み、2026-10-12）

```lean
example (α : Type) (F : α → Prop) : ¬(∃ x, F x) → ∀ x, ¬F x := by
  intro h1         -- (1) ¬∃xFx を仮定
  intro t          -- 任意の t を取る（全称汎化の準備）
  intro h2         -- (2) Ft を仮定（¬Ft = Ft → False）
  exact h1 ⟨t, h2⟩ -- ⟨t, h2⟩ : ∃xFx（存在汎化）。h1 に渡して矛盾
```

- 全称汎化は Lean では `intro t`（任意の t を取る）。Lean は t について何も仮定していない状態で `intro` させるので、限定つきの項の問題が起きない。
- 存在汎化は `⟨t, h2⟩`（t と、Ft の証明をペアにする）。

Lean のコードの読み方

前提: Lean の ¬P は P → False の略記。この定理は Lean の中では `((∃ x, F x) → False) → ∀ x, (F x → False)`。¬ を → False に読み替えると、intro できる理由が分かる。

`¬(∃ x, F x)` のカッコは必要。カッコなしだと `∃ x,` が右端までかかってしまう（量化の範囲は本と逆）。

ゴールの変化

```
⊢ ¬(∃ x, F x) → ∀ x, ¬F x
      │ intro h1   「→ を示すには、左を仮定して右を示せばいい」
      ▼
⊢ ∀ x, ¬F x
      │ intro t    「∀ を示すには、任意の t について示せばいい」
      ▼
⊢ ¬F t           （= F t → False）
      │ intro h2   「→ を示すには、左を仮定して右を示せばいい」
      ▼
⊢ False
      │ exact h1 ⟨t, h2⟩   「手元の材料で False が作れる。おしまい」
      ▼
   完成
```

- `intro t`: `t : α` が手元に入る。t について他に何も分かっていない状態 = 本の「何でもいい t」。全称汎化にあたる。
- `intro h2`: ゴールが `False` になる = 「矛盾を示せ」。背理法の始まり。
- `⟨t, h2⟩`: ∃ の証明は「具体的なもの」と「それが条件を満たす証明」のペア。t と h2 : F t をペアにして `∃ x, F x`（存在汎化）。
- `h1 ⟨t, h2⟩`: h1 は「∃ の証明を渡されたら False を返す」関数。①を渡して False。

本と Lean の対応

| 本 | Lean | やっていること |
| --- | --- | --- |
| 1行目 仮定、7行目 DR | `intro h1` | ¬∃xFx を仮定 |
| 6行目 全称汎化 | `intro t` | 任意の t を取る |
| 2行目 仮定、5行目 背理法 | `intro h2` | Ft を仮定し、ゴールを False にする |
| 3行目 存在汎化 | `⟨t, h2⟩` | t と Ft の証明をペアにして ∃xFx |
| 4行目 結合（矛盾） | `h1 ⟨t, h2⟩` | ¬∃xFx に ∃xFx を渡して False |

- 順番が逆: Lean はゴールから逆算するので、本で後に来る DR・全称汎化・背理法が intro として先に来る（[lean.md](lean.md) の「ゴールから逆算」）。
- 矛盾は False: ¬ が → False なので、h1 に渡すだけで False が出る。
- 限定つきの項はチェック不要: Ft を仮定する前に intro t するので、t は自然に「何でもいい t」になる。
- 1行で書くと `fun h1 t h2 => h1 ⟨t, h2⟩`。
