# 述語論理の構文論（第4節）：全称例化（問題49・50）

## 使う公理系：述語論理の公理系（LP の拡張）

命題論理の公理系 LP に、量化子に関する規則（導入則と除去則、4つ）を付け加えたもの。ここまでに出てきたのは全称例化だけ。残りの量化子の規則は、出てきたら追記する。

### 命題論理の規則（LP より）

詳しくは [lp.md](lp.md)。

- 演繹規則 DR: A を仮定して B が導出されるとき、A という仮定なしに A ⊃ B を導出してよい
- 前件肯定式 MP: A, A ⊃ B から B を導出してよい
- 背理法: A ⊃ (D ∧ ¬D) から ¬A を導出してよい
- 二重否定: ¬¬A から A を導出してよい
- 結合: A, B から A ∧ B を導出してよい
- 分離: A ∧ B から A を、A ∧ B から B を導出してよい
- ∨入れ: A から A ∨ B を、B から A ∨ B を導出してよい
- ∨取り: A ∨ B, A ⊃ C, B ⊃ C から C を導出してよい

### 量化子の規則

- 全称例化（∀ の除去則）: **∀xAx から At を導いてよい**

### 図式的表現の読み方

- At は、定項ないし自由変項 t を含む何らかの論理式を表す。∀xAx は、変項 x を含む何らかの論理式を全称量化したもの。A は述語記号ではなく、ある特徴をもった無限個の論理式を代表している（図式的表現）。
- 「A から B を導出してよい」を「A → B」と書く。

1. 一番単純な例: ∀xFx → Ft。t は任意の定項ないし変項で、記号は t でなくてもよい（∀xFx → Fa でも ∀xFx → Fx でもよい）。
2. Ax は複数の命題関数から構成されていてもよい: ∀x(Fx ∨ Gx) → Ft ∨ Gt。ただし**量化子は必ず Ax 全体にかかっていること**。∀xFx ∨ ∀xGx → Ft ∨ Gt や ∀xFx ∨ ∃xGx → Ft ∨ ∃xGx はダメ。
3. Ax は複数の定項ないし変項を含んでいてよい: ∀xFxy → Fty、∀x∃yFxy → ∃yFty。ただし ∃y∀xFxy → ∃yFty はダメ（一番外側が ∀x ではない）。

### 証明の仕方・仮定の扱い（LP と同じ）

1. 各行には、仮定、定理、先行する行から導出規則で導出できる式のいずれかを書く。
2. 目的の式が仮定なしに書き出されたら終わり。
3. A を n 行目で仮定するときは A [n]。導出に使った式の仮定はすべて受け継がれ、DR で外した仮定だけが消える。

### メモ

- 意味論（妥当式、すべての解釈で真）に対して、構文論は意味抜きの記号変形の体系（公理系）。述語論理には決定手続きがないので、構文論（証明）が命題論理よりはるかに重要になる。
- 全称例化の直感: 「すべての x について A」なら「特定の t について A」も言える（すべての人間は死ぬ → ソクラテスは死ぬ）。
- 構文論は意味を見ず、**記号の形だけ**を見る。∀xFx ∨ ∀xGx → Ft ∨ Gt は意味としては正しい推論だが、一番外側が ∨ なので全称例化を1回では使えない。命題論理で「一番外側の ⊃ で切る」と考えたのと同じ。
- Lean では、`h : ∀ x, F x` に t を渡して `h t : F t`。全称例化は関数適用（MP と同じ形）。

### Ax の当てはめ方

Ax の A は、命題論理のときの □ と同じ空欄。「x を含む式なら何でも」入る（Fx ⊃ Gx のような複合的な式も入る）。

> ∀x( □ ) から、□ の中の x を**全部** t に置き換えた式を導いてよい

```
∀x( Fx ⊃ Gx )
    └── □ ──┘    □ = Fx ⊃ Gx  →  t = a で Fa ⊃ Ga
```

- x が何か所にあっても、全部同じ t に置き換える（Fa ⊃ Gb はダメ）。
- 条件は1つだけ: ∀x のカッコが □ 全体を囲んでいること。∀xFx ⊃ Gx（カッコなし）は ∀x が Fx にしかかからないのでダメ。¬∀xFx も ∀x の外側に ¬ があるのでダメ（問題49）。

| 元の式 | □（Ax） | t = a のとき（At） |
| --- | --- | --- |
| ∀xFx | Fx | Fa |
| ∀x(Fx ⊃ Gx) | Fx ⊃ Gx | Fa ⊃ Ga |
| ∀x(Fx ∨ Gx) | Fx ∨ Gx | Fa ∨ Ga |
| ∀x¬Fx | ¬Fx | ¬Fa |
| ∀x∃yFxy | ∃yFxy | ∃yFay |

## 問題

### 問題49

次の偽定理に対する偽証明の誤りを指摘せよ。

偽定理 ¬∀xFx ⊃ ¬Fa

| 行 | 論理式 | 仮定 | 根拠 |
| --- | --- | --- | --- |
| 1 | ¬∀xFx | [1] | 仮定 |
| 2 | ¬Fa | [1] | 1 と全称例化 |
| 3 | ¬∀xFx ⊃ ¬Fa | なし | 1, 2 と DR |

- 状態: 本の解答を確認済み

解答（本より）: ¬∀xFx は ∀xAx という形ではないから（式の冒頭に ¬ がついている）、¬∀xFx から ¬Fa を導出することは許されない。

メモ

- 2行目が誤り。全称例化は「∀x( … )」の形の式にしか使えない。¬∀xFx は一番外側が ¬ なので形が合わない。
- 意味で考えても偽: ¬∀xFx は「すべてが F というわけではない」。F でないものが**どこかに**あるだけで、a がそれだとは限らない。
- 反例になる解釈: D = 動物、Fx = x は肉食である、a = ライオン。¬∀xFx（すべての動物が肉食ではない）は真、¬Fa（ライオンは肉食ではない）は偽。真 ⊃ 偽 なので偽。

### 問題50

次の定理に対する証明の空欄を埋めよ。

定理 (∀x(Fx ⊃ Gx) ∧ Fa) ⊃ Ga

| 行 | 論理式 | 仮定 | 根拠 |
| --- | --- | --- | --- |
| 1 | ∀x(Fx ⊃ Gx) ∧ Fa | [1] | 仮定 |
| 2 | ∀x(Fx ⊃ Gx) | [1] | 1 と分離 |
| 3 | Fa | [1] | 1 と分離 |
| 4 | （空欄） | [1] | 2 と全称例化 |
| 5 | Ga | [1] | 3, 4 と MP |
| 6 | (∀x(Fx ⊃ Gx) ∧ Fa) ⊃ Ga | なし | 1, 5 と DR |

- 状態: 本の解答を確認済み

解答（本より）: Fa ⊃ Ga

メモ

- 2行目 ∀x(Fx ⊃ Gx) は、Ax = Fx ⊃ Gx として全称例化できる（量化子が Fx ⊃ Gx 全体にかかっている）。t = a を選んで Fa ⊃ Ga。
- なぜ a を選ぶか: 3行目に Fa があるので、MP で Ga を取り出すには Fa ⊃ Ga が欲しい（ゴールからの逆算）。
- 意味: 「すべての F は G で、a は F なら、a は G」。三段論法（すべての人間は死ぬ、ソクラテスは人間、ゆえにソクラテスは死ぬ）。

Lean で書くと（動作確認済み、2026-10-12）

```lean
example (α : Type) (F G : α → Prop) (a : α) : (∀ x, F x → G x) ∧ F a → G a := by
  intro h          -- (1) 仮定
  have h2 := h.1   -- (2) 分離
  have h3 := h.2   -- (3) 分離
  have h4 := h2 a  -- (4) 全称例化：Fa → Ga
  exact h4 h3      -- (5) MP
```

Lean のコードの読み方

1行目（何を証明するか）: `:` の前が準備（登場するもの）、後が証明したい式。

| Lean | 意味 | 本で言うと |
| --- | --- | --- |
| `example` | 名前なしの定理 | 定理 |
| `(α : Type)` | 何かの型 α | 議論領域 D |
| `(F G : α → Prop)` | α の要素を受け取って命題を返す F と G | 述語 F, G |
| `(a : α)` | α の要素 a | 定項 a |
| `(∀ x, F x → G x) ∧ F a → G a` | 証明したい式 | (∀x(Fx ⊃ Gx) ∧ Fa) ⊃ Ga |
| `:= by` | ここからタクティクで証明する | 証明 |

Lean では `∧` のほうが `→` より強く結びつくので、`(∀ x, F x → G x) ∧ F a → G a` は `((∀ x, F x → G x) ∧ F a) → G a` と読まれる。

各ステップ後の Infoview（`⊢` の上が今使える仮定、下が今示すべきゴール）

```
-- intro h の後
h : (∀ x, F x → G x) ∧ F a
⊢ G a

-- have h2, h3 の後
h2 : ∀ x, F x → G x
h3 : F a
⊢ G a

-- have h4 の後
h4 : F a → G a
⊢ G a
```

- `intro h`: ゴール `A → B` の左側 A を仮定して h と名付け、ゴールを B にする。
- `h.1`, `h.2`: `P ∧ Q` の証明から左・右を取り出す（分離）。`have 名前 := 式` は、新しい行を書くのにあたる。
- `h2 a`: `h2 : ∀ x, F x → G x` は「x を渡されたら F x → G x を返す」関数。a を渡すと x が a に置き換わって `F a → G a`（全称例化）。
- `h4 h3`: `h4 : F a → G a` は「F a の証明を渡されたら G a の証明を返す」関数。`h3 : F a` を渡して `G a`（MP）。`exact` は「これがゴールの答えそのもの」という宣言。

本と Lean の対応

| 本 | Lean | やっていること |
| --- | --- | --- |
| 1行目 仮定、6行目 DR | `intro h` | 左側を仮定し、ゴールを右側にする |
| 2行目 分離 | `h.1` | ∧ の左を取り出す |
| 3行目 分離 | `h.2` | ∧ の右を取り出す |
| 4行目 全称例化 | `h2 a` | ∀ の関数に a を渡す |
| 5行目 MP | `h4 h3` | → の関数に Fa の証明を渡す |

- 本では DR は最後（6行目）だが、Lean では最初に `intro` する。Lean はゴールから逆算して進むので、「A ⊃ B を示したい → A を仮定して B を示せばいい」と最初に宣言する。`intro` 1回で、本の仮定（1行目）と DR（6行目）の両方をやっている。
- 本の [ ] の番号は、Lean では `⊢` の上の仮定一覧として自動で管理される。
- **全称例化も MP も、Lean ではどちらも「関数に何かを渡す」**。∀ には個体（a）を、→ には証明（h3）を渡す。
- 1行にまとめると `exact h.1 a h.2`。
