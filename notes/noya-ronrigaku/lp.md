# 命題論理の公理系 LP（1-2-3 命題論理の完全な公理系の例）

## 使う公理系：命題論理の公理系 LP

サンプル2を拡張して、完全にしたもの。本当に完全かどうかは、メタ論理で証明すべき課題。

- 規則1［演繹規則 DR］: A を仮定して B が導出されるとき、A という仮定なしに A ⊃ B を導出してよい
- 規則2［前件肯定式 MP］: A, A ⊃ B から B を導出してよい
- 規則3［背理法］: A ⊃ (D ∧ ¬D) から ¬A を導出してよい
- 規則4［二重否定］: ¬¬A から A を導出してよい
- 規則5［結合］: A, B から A ∧ B を導出してよい
- 規則6［分離］:
  1. A ∧ B から A を導出してよい
  2. A ∧ B から B を導出してよい
- 規則7［∨入れ］:
  1. A から A ∨ B を導出してよい
  2. B から A ∨ B を導出してよい
- 規則8［∨取り］: A ∨ B, A ⊃ C, B ⊃ C から C を導出してよい
- 定義: A ≡ B は (A ⊃ B) ∧ (B ⊃ A) の略記である

（A, B, C, D は任意の論理式）

### 証明の仕方

1. 証明の各行には、次のいずれかの論理式を書く。
   1. 仮定
   2. 定理（証明済みの論理式）
   3. 先行する行の論理式から、導出規則で導出できる論理式
2. 目的の論理式が**仮定なしに**書き出されたら、証明は終わる。

### 仮定の扱い

1. 論理式 A を n 行目で仮定するときは、A [n] と書く。
2. 仮定 n1, …, nk のもとで書かれた式は A [n1, …, nk] と書く。
3. 導出に使った式の仮定は、すべて導出結果に受け継がれる。規則1を使ったときだけ、外した仮定の番号が消える。

## サンプル2との違い

**規則の番号がずれている**ので注意。

| LP | 名前 | サンプル2 |
| --- | --- | --- |
| 規則1 | 演繹規則 DR | 規則1 |
| 規則2 | 前件肯定式 MP | 規則2 |
| 規則3 | 背理法 | 規則3 |
| 規則4 | 二重否定 | **新規** |
| 規則5 | 結合 | 規則4 |
| 規則6 | 分離 | 規則5 |
| 規則7 | ∨入れ | **新規** |
| 規則8 | ∨取り | **新規** |

- 二重否定（¬¬A から A）が加わった。サンプル2では A ⊃ ¬¬A（例題7）は示せたが、逆向きは示せなかった。
- ∨ を扱う規則（作る：規則7、使う：規則8）が加わった。
- ≡ は新しい記号ではなく、⊃ と ∧ の組み合わせの略記。

## 記号ごとの「作る規則」と「使う規則」

| 記号 | 作る | 使う |
| --- | --- | --- |
| ⊃ | 規則1（DR） | 規則2（MP） |
| ∧ | 規則5（結合） | 規則6（分離） |
| ∨ | 規則7（∨入れ） | 規則8（∨取り） |
| ¬ | 規則3（背理法） | 規則4（二重否定） |

## 操作は3種類（復習）

| 種類 | やること | 規則 |
| --- | --- | --- |
| ① 仮定を置く（箱を開ける） | 好きな式を書く | なし |
| ② 式を作る | 前の行を材料に、規則の形に当てはめて新しい式を出す | 規則2〜8 |
| ③ 仮定を外す（箱を閉じる） | 「仮定〜結論」の塊を □ ⊃ △ にまとめる | 規則1 |

## 命題論理の諸定理（本 p.70）

LP で証明できる主な定理。証明済みの定理として、証明の中で使ってよい。

| 番号 | 定理 | 名前 |
| --- | --- | --- |
| 定理1 | A ⊃ A | 同一律 |
| 定理2 | A ∨ ¬A | 排中律 |
| 定理3 | ¬(A ∧ ¬A) | 矛盾律 |
| 定理4 | (D ∧ ¬D) ⊃ A | |
| 定理5 | ((A ⊃ B) ∧ A) ⊃ B | 前件肯定式 |
| 定理6 | ((A ⊃ B) ∧ ¬B) ⊃ ¬A | 後件否定式 |
| 定理7 | (A ⊃ B) ⊃ (¬B ⊃ ¬A) | 対偶律 |
| 定理8 (1) | ((A ∨ B) ∧ ¬A) ⊃ B | 選言的三段論法 |
| 定理8 (2) | ((A ∨ B) ∧ ¬B) ⊃ A | 選言的三段論法 |
| 定理9 (1) | ¬(A ∨ B) ≡ ¬A ∧ ¬B | ド・モルガンの法則 |
| 定理9 (2) | ¬(A ∧ B) ≡ ¬A ∨ ¬B | ド・モルガンの法則 |
| 定理10 | ¬A ∨ B ≡ A ⊃ B | |
| 定理11 | ((A ⊃ B) ∧ (B ⊃ C)) ⊃ (A ⊃ C) | 推移律 |
| 定理12 (1) | A ∧ (B ∨ C) ≡ (A ∧ B) ∨ (A ∧ C) | 分配律 |
| 定理12 (2) | A ∨ (B ∧ C) ≡ (A ∨ B) ∧ (A ∨ C) | 分配律 |

メモ

- 定理11（推移律）は、問題25(3) でサンプル2を使って証明したものと同じ式。
- 定理5（前件肯定式）は、サンプル2の本文の例2 (A ∧ (A ⊃ B)) ⊃ B と ∧ の左右が入れ替わっただけ。
- 定理4は「矛盾からは何でも出てくる」という式。
- ≡ を含む定理（9, 10, 12）は、≡ の定義により「⊃ を両方向」証明することになる。
