# 述語論理の記号化（問題39）

## 使う公理系

なし（日本語の文を述語論理の記号で表す練習）。用語と記号は [pred-basics.md](pred-basics.md)。

### 必要な記号（復習）

- 述語 F, G, …、変項 x, y, …、定項 a, b, …
- 命題関数 Fx（x は〜である）、命題 Fa
- ∀xFx: すべての x について Fx、∃xFx: ある x について Fx
- 量化子は、カッコがなければ直後の式だけにかかる（∃xFx ∧ Gx と ∃x(Fx ∧ Gx) は違う）
- 議論領域 D を定めないときは、「人間である」なども述語で書く

## 問題39

次の文を述語論理の記号を用いて表わせ。

1. ムササビは鳥ではない
2. 飛ばない鳥もいる
3. 強くなければ男じゃない
4. 必ずしも強くなければ男じゃないというわけではない

- 状態: 本の解答を確認済み

解答（本より）

| 問 | 述語の設定 | 記号化 |
| --- | --- | --- |
| (1) | Fx: x はムササビである、Gx: x は鳥である | ∀x(Fx ⊃ ¬Gx) |
| (2) | Fx: x は飛ぶ、Gx: x は鳥である | ∃x(¬Fx ∧ Gx) |
| (3) | Fx: x は強い、Gx: x は男だ | ∀x(¬Fx ⊃ ¬Gx) |
| (4) | (3) と同じ | ¬∀x(¬Fx ⊃ ¬Gx) |

メモ

- 型: **「すべての F は G」→ ∀x(Fx ⊃ Gx)**、**「ある F は G」→ ∃x(Fx ∧ Gx)**。∀ には ⊃、∃ には ∧ が付くのが基本。
- (1) よくある間違い: ∀x(Fx ∧ ¬Gx) だと「すべてのものはムササビで、かつ鳥ではない」になってしまう。
- (2) よくある間違い: ∃x(¬Fx ⊃ Gx) だと、飛ぶものが1つでもあれば（¬Fx が偽なので）真になってしまい、弱すぎる。
- (1)(3) は「すべて」と書かれていないが、「ムササビというものは」「（誰でも）強くなければ」という一般的な主張なので ∀ で表す。
- (4) は (3) の全体を否定したもの。「強くなくても男である人がいる」と同じで、∃x(¬Fx ∧ Gx) とも書ける（¬∀ は ∃¬ に、¬(P ⊃ Q) は P ∧ ¬Q になる）。

Lean で書くと（α は議論領域の型、F G : α → Prop）

```lean
∀ x, F x → ¬G x          -- (1)
∃ x, ¬F x ∧ G x          -- (2)
∀ x, ¬F x → ¬G x         -- (3)
¬∀ x, ¬F x → ¬G x        -- (4)
```

(4) の ¬∀x(¬Fx ⊃ ¬Gx) ≡ ∃x(¬Fx ∧ Gx) は Lean で確認済み（2026-10-12）。∃ → ¬∀ の向きは古典論理なしで示せるが、¬∀ → ∃ の向きは `Classical.byContradiction` が必要。
