# 野矢茂樹『論理学』（東京大学出版会）練習問題ノート

まず手で解き、あとで Lean で形式化して確かめる予定。

## 公理系・定理の一覧

### 公理系のサンプル1

- 公理1: (A ∨ A) ⊃ A
- 公理2: A ⊃ (A ∨ B)
- 導出規則1: A と A ⊃ B から B を導出してよい
- 導出規則2: A ⊃ B と B ⊃ C から A ⊃ C を導出してよい

（A, B, C は任意の論理式）

### 証明済みの定理

- [同一律] A ⊃ A

## 証明の仕方

1. 証明の各行には、次のいずれかの論理式を書く。
   1. 公理（の代入例）
   2. 定理（証明済みの論理式）
   3. 先行する行の論理式から、導出規則で導出できる論理式
2. 目的の式が書き出されたら、証明は終わる。

## 問題

### 問題23

公理系のサンプル1と定理［同一律］を用いて、次を証明せよ。

1. (A ⊃ A) ∨ B
2. (A ∨ A) ⊃ (A ∨ B)

- 状態: 本の解答を確認済み

解答（本より）

(1) 定理 (A ⊃ A) ∨ B

| 行 | 論理式 | 根拠 |
| --- | --- | --- |
| 1 | A ⊃ A | 定理［同一律］ |
| 2 | (A ⊃ A) ⊃ ((A ⊃ A) ∨ B) | 公理2 の A に A ⊃ A を代入 |
| 3 | (A ⊃ A) ∨ B | 1, 2 と導出規則1 |

(2) 定理 (A ∨ A) ⊃ (A ∨ B)

| 行 | 論理式 | 根拠 |
| --- | --- | --- |
| 1 | (A ∨ A) ⊃ A | 公理1 |
| 2 | A ⊃ (A ∨ B) | 公理2 |
| 3 | (A ∨ A) ⊃ (A ∨ B) | 1, 2 と導出規則2 |

メモ

- (1) のポイント: 公理2 の A には「任意の論理式」を入れてよいので、A ⊃ A という複合的な式も代入できる。
- (1) は「欲しい式 X ∨ B を作るには、公理2 で X ⊃ (X ∨ B) を用意し、X そのものを別に示す」という形。導出規則1（モーダス・ポネンス）の典型的な使い方。
- つまずいた点: 導出規則の A, B は「空欄」で、式の中の A, B とは別物。規則1 を「□ と □ ⊃ △ がそろったら △」と読むと分かりやすい。(1) では □ = A ⊃ A、△ = (A ⊃ A) ∨ B。2行目は一番外の ⊃ で左右に切る。
- (2) は ⊃ を連鎖させる導出規則2（三段論法）を使うだけ。公理1と公理2はそのまま（代入なし）で使える。
